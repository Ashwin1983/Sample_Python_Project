\# Simple Flask Login Application



This is a simple Python Flask web application that displays a basic login page.



\## Features



\- Simple login form

\- Username and password validation

\- Clean UI using HTML and CSS

\- Flask backend

\- Beginner-friendly project



\---



\## Project Structure



```text

project-folder/

│

├── app.py

└── README.md

```



\---



\## Prerequisites



Make sure Python is installed on your system.



Check Python version:



```bash

python --version

```



\---



\## Install Required Package



Install Flask using pip:



```bash

pip install flask

```



\---



\## Run the Application



Execute the following command:



```bash

python app.py

```



\---



\## Access the Application



Open your browser and navigate to:



```text

http://127.0.0.1:5000

```
